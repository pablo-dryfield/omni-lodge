Note: This tool is available only to authorized internal users. Mockups are included to show the reporting and campaign-management workflows.

Company Name: Krawl Through Krakow / Krakow Food Tour

Business Model: Our company operates guided tourism experiences in Krakow and sells tickets directly to consumers through websites owned by our business: krawlthroughkrakow.com and krakowfoodtour.com. We advertise only our own tour brands and do not manage advertising for unrelated clients.

Tool Access/Use: OmniLodge is an internal operations, reporting and campaign-management tool used only by authorized employees and contractors. The public and tour customers cannot access it. Internal administrators use the tool to review Google Ads performance together with booking and revenue data. The planned campaign-management workflow will let administrators prepare and manage campaigns for our owned accounts. New campaigns are created paused and require human review of creative content, URLs, conversion tracking and budgets before activation.

Tool Design: The Node.js/Express backend authenticates to the Google Ads API using OAuth 2.0, the developer token and our manager-account context. The backend retrieves account, campaign, ad-group and performance data for the internal React interface. Reporting data is combined with internal booking data stored in PostgreSQL. For campaign management, an administrator selects an approved source structure, reviews a food-tour-specific proposal, validates the operations and creates the destination resources in a paused state. OAuth credentials and the developer token remain server-side and are not exposed to users.
API Services Called:
  • Retrieve account structure and performance using GoogleAdsService Search/SearchStream and the Customer/CustomerClient resources.
  • Create and manage budgets and campaigns using CampaignBudgetService and CampaignService.
  • Create and manage ad groups, responsive search ads and Demand Gen ads using AdGroupService and AdGroupAdService.
  • Create and manage keywords, negative keywords and targeting using AdGroupCriterionService and CampaignCriterionService.
  • Create and associate supported creative assets using AssetService and campaign/ad-group asset services.
Tool Mockups: The reporting screen summarizes account performance. The campaign-preparation screen shows the approved reference campaigns and makes the paused status explicit before creation.
